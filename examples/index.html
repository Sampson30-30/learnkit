LearnKit examples

About this page

What this is. Every LearnKit building block, working, on one page. The heading above each one is its name, such as lk-quiz.

What you can do here

  • Try each block: click it, type in it, and use the keyboard.
  • Note the names of the ones you like. When you ask Claude to build something, you can use those names. For example: “use an lk-quiz for the check at the end”.
  • Ignore the short pieces of code in grey. They are for Claude, and for whoever looks after the code.

lk-tabs

Each child marked with data-lk-tab becomes a tab.

Use the arrow keys, Home and End to move between tabs.

Listen for the lk-tabchange event to track progress.

lk-accordion

One section is open at a time by default.

Use the up and down arrows, Home and End to move between headings.

Press Enter or Space to open or close a section.

With multiple

Yes. Add the multiple attribute.

Set level from 1 to 6. The default is 3.

Listen for lk-toggle.

lk-modal

Focus stays inside while this is open. Press Escape, use the close button or click outside to dismiss it.

Focus returns to the button you used to open it.

This cannot be undone. Clicking outside does nothing here because the modal has the static attribute.

LearnKit theme gallery

Every building block in every look, using the same content each time so you can compare fairly.

About this page

What this is. A component is one ready-made block, such as a quiz or a tab set. A theme is a complete look for all the blocks: colours, corners and fonts. This page shows them side by side.

What you can do here

  • Choose “One component, all themes” to see one block in every look.
  • Choose “One theme, all components” to see one look across every block.
  • Switch between light and dark, to check a look works in both.
  • When you find a look you like, tell Claude its name. For example: “use the Clean theme”.
View
Mode

To use a look in something you are building, tell Claude its name. You do not need to do anything else.

For the person who looks after the code

Load learnkit.css, then the theme file, then set data-lk-theme="name" on <html> or any wrapper. See the theming guide.
